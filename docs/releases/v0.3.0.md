# CrabCache v0.3.0 — CrabPack

CrabPack adds optional, transparent compression of idle values with zstd dictionaries trained per
key prefix. Existing Redis clients keep using GET/SET: reads return the original bytes, writes store
plain values, and compression can be enabled without changing the client protocol.

Enable it locally:

```bash
crabcache --compression
```

Or with the Docker image:

```bash
docker run -d --name crabcache -p 127.0.0.1:6379:6379 \
  -e CRABCACHE_REQUIREPASS=replace-this-password \
  -e CRABCACHE_COMPRESSION=true \
  rogerfelipensk/crabcache:v0.3.0
```

Compression is **off by default**. Defaults when enabled: 60 seconds idle and minimum value size
of 64 bytes. Use `INFO compression` to inspect dictionaries, packed keys and payload ratios.
`CONFIG SET compression yes|no`, `compression-min-idle` and `compression-min-size` can change these
settings at runtime. Disabling compression leaves already packed values readable.

Three local benchmark repetitions on Apple M1 Pro/macOS showed **55–63% less incremental memory
than Redis 8.10.2** for synthetic JSON datasets of 300,000 keys. Decompression costs CPU and reduced
GET throughput in the measured workloads. Raw results and limitations are in
[BENCHMARKS.md](https://github.com/RogerFelipeNsk/crabcache/blob/v0.3.0/docs/BENCHMARKS.md).

Validation includes 57 tests in release/debug, a local differential run with 1.53 million generated
commands against Redis, seven benchmark regression tests and independent recalculation of 99
measurements. The CI covers Linux/macOS, Rust 1.85, dependency audit, published data consistency and
the Docker image, including a CrabPack test of 2,000 binary values with TTL.

This is an **experimental cache release**: strings only; no persistence, replication or transactions.
CrabPack phase 1 has no dictionary retraining; training uses temporary memory, and already packed
values remain packed until rewritten. See the
[README](https://github.com/RogerFelipeNsk/crabcache/blob/v0.3.0/README.md#ativando-o-crabpack)
for configuration and a reproducible local demo.
